# Deploy: reservations v2 + online meals v2 + staff home status (Nov 2026)

Server: pm.thanjaicaterers.com (VPS 192.169.177.188, user `thanjai`), app folder `~/code/thanjai_api`, branch `reservations`,
service `TR`, database `thanjai_restaurant`. The UI is already built into `client/build` - nothing to build on the server.

## What is in this release
- **Reservations**: start times every 30 min per session (Lunch 11:00-14:30, Dinner 17:00-21:30, editable), table held 90 min,
  A-series booths cannot be joined (groups above 4 get B / C), guests may book without choosing tables, staff allocate tables
  and the guest is e-mailed, staff "New booking" button, timeline reports.
- **Online meals**: Veg / Non-Veg plans with a fixed weekly price (any dishes of that kind, costly limit), Combo plans = mix of
  veg and non-veg at regular price less a discount, Dish prices screen from Product Master (online switch, diet, price, own
  discount, costly; Excel import optional), new landing page (Cumin Club style), order review without per-dish prices for
  Veg / Non-Veg.
- **Staff home**: traffic-light tiles for Reservations (today, tables to allocate) and Online (menu, orders and weekly steps,
  shop setup), next to the existing Indents / Invoices / Payments / stock tiles.
- Database migrations **012_reservation_slots**, **013_meal_pricing**, **014_dish_discount** (safe to run again).

It adds to what is on GitHub (includes the Nov 2 traffic-light home).

## 2. On the VPS (one line at a time)

## 3. Setup after deploy (staff, in the app)
**Reservations** (Reservations → Reservation setup)
1. Sessions & times: check Lunch 11:00-14:30 and Dinner 17:00-21:30 every 30 min (change if needed).
2. Tables: set the table that is really a 2-seater (the plan has 72 chairs, the drawing says 70); A1-A6 show "cannot be joined".
3. Limits & contact: restaurant e-mail, reservable chairs (40), table time (90 min).

**Online meals** (Online → Shop setup, then Weekly menu)
1. Delivery zones: add the zones (postal code starts + fee).
2. Plans: enter the **weekly price** of every Veg / Non-Veg plan (plans without one stay hidden) and "Costly dishes allowed".
3. Dish prices: switch **Online** on for the dishes sold, set diet and regular price, tick **Costly**; set the **Combo default
   discount** (and a dish's own % where different). Excel import is optional.
4. Weekly menu: add the dishes for the next delivery date, mark chef's picks, **Publish**.

**Roles** (Master → Role): screens RES_BOOKINGS / RES_REPORTS / RES_SETUP and SUB_ORDERS / SUB_SETUP / SUB_CUSTOMERS decide
who sees the Reservations / Online menus and their home tiles.

## 4. Quick check after setup
- Staff home shows the Reservations and Online tiles.
- /v1/reserve: 6 guests → A tables greyed; book a time without tables → staff see it under "Tables to allocate"; allocate →
  guest e-mail arrives.
- /v1/meals: Veg plan shows "$xx a week · any N dishes"; Combo shows dish prices with the discount; checkout totals add
  delivery, GST and QST.

(`ad8e2ec` = the version running before this release.) The new columns / tables can stay. To restore the data as well:
